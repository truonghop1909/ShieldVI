# Tài liệu lưu trữ

Các tài liệu này giữ nguyên bối cảnh thời điểm viết; không dùng chúng thay cho
[hướng dẫn chạy hiện hành](../ai-update/final-report/REALTIME_DEMO_GUIDE.md).

- `implementation_reports/`: báo cáo triển khai Social T007–T019.
- `merges/`: lịch sử gộp repository và tài liệu.
- `legacy_guides/`: README V3, hướng dẫn sao chép và prompt khởi động cũ.

Tài liệu thiết kế ban đầu nằm ở [design](../design/00_MUC_LUC.md). Báo cáo các
thực nghiệm AI vẫn giữ cấu trúc phiên bản trong `ai-update/final-report/` để
phân biệt số liệu lịch sử với kết quả và acceptance hiện tại.

Các snapshot kiểm thử trong `docs/baseline/`, bằng chứng trong
`docs/repository-merge-evidence/` và readiness manifests giữ nguyên đường dẫn.
Đây là bằng chứng hoặc bản sao phục hồi, không phải các bản hướng dẫn đang
được duy trì song song.
